# UI主题调整

现在我想将整个UI框架都迁移到SukiUI，这是一个Avalonia UI的主题：https://github.com/kikipoulet/SukiUI，当前最新版本为6.0.3
安装指令为：`dotnet add package SukiUI`

## 要求

完整迁移，不要留有任何原来的UI框架与内容

## 界面框架

左侧是侧边栏，用来放置不同的界面，可以切换，包含下述界面

- 启动：包含主要的启动按钮，以及Log，强制结束所有进程
- 显示器布局：用于双显示器的设置，暂时只有一个屏幕旋转以及其相关的功能，目前还未想好怎么设计，请先创建位置进行占位
- 游戏设定：包含现有程序内所有的设定
    - 包含：窗口化启动，不启动氧无，
    - 高级选项中的：NetDump，调试模式启动氧无，禁用副屏，窗口化模式，大小核优化，副屏无边框，显示光标&触控模拟
    - AMD/Intel显卡兼容层
- 常用工具：以卡片的形式排布
    - 清除Data_Mods缓存
    - 添加防火墙规则
    - 打开音频控制面板
    - 安装运行库
- 关于：说明启动的相关信息，版本号，游戏版本号，上方显示Logo
